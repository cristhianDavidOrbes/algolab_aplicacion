# AlgoLab

Proyecto educativo de realidad mixta desarrollado en Unity para Meta Quest.

## Abrir el proyecto

1. Instala Unity `6000.3.18f1` con soporte de compilación para Android.
2. Abre esta carpeta desde Unity Hub.
3. Abre `Assets/Scenes/version_estable14.unity`.

La escena incluida en Build Settings es `version_estable14`. Las carpetas
`Library`, `Temp`, `Builds`, cachés y dependencias instaladas no se versionan
porque Unity y los módulos externos pueden regenerarlas.

## Módulos externos

El código fuente de IA y de la aplicación web está en `ModulosExternos`.
Las dependencias se instalan desde sus archivos de configuración; los entornos
virtuales, `node_modules`, compilaciones y secretos locales no se publican.
